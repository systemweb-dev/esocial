## Campos do `stdClass`

As chaves podem vir em qualquer caixa (a lib converte para minúsculo). Grupos com itens são arrays de objetos.

| Campo | Tipo | Obrig. | Regra | Descrição |
|---|---|---|---|---|
| `sequencial` | integer | não | 1 a 99999 | Sequencial do Id do evento (1 a 99999). Opcional: sem ele a lib sorteia um; entre processos, quem chama deve alocar (ver docs/Config.md). |
| `ideproc` | object | sim |  | Identificação do processo. |
| `ideproc/nrproctrab` | string | sim | `^([0-9]{17}\|[0-9]{20}\|[0-9]{21})$` | Número do processo trabalhista, da ata ou número de identificação da conciliação. Validação: Deve ser um número de processo válido. |
| `ideproc/perapurpgto` | string | sim | `^([2]{1}[0-9]{3}-(1[0-2]\|0[1-9])\|[2]{1}[0-9]{3})$` | Mês/ano em que é devida a obrigação de pagar a parcela prevista no acordo/sentença. Validação: Deve ser informado no formato AAAA-MM. |
